# Projeto Curso HTML/CSS - 1

Projeto do curso de HTML e CSS, com os exercícios de criação de páginas e o portfólio final, feitos do zero.

## Páginas

| Arquivo | Descrição |
| --- | --- |
| `index.1.html` | Meu Primeiro Site |
| `index.2.html` | Meu segundo site |
| `portfólio.html` | Portfólio do curso |

Para abrir uma página, basta dar um duplo clique no arquivo `.html` ou arrastá-lo para o navegador.

## Estrutura

```
.
├── css/        # Folhas de estilo (style.css, style.1.css, style.2.css)
├── images/     # Imagens usadas nas páginas
├── docs/       # Documentação e anotações do curso
├── index.1.html
├── index.2.html
└── portfólio.html
```

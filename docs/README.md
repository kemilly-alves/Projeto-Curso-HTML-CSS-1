# Documentação

Esta pasta reúne a documentação do projeto. Cada assunto fica em um arquivo `.md` próprio, e as versões em PDF ficam em [`PDF/`](PDF/).

## Índice

1. [HTML5 e CSS: aprendendo a criar sites do zero na prática](html5-css-introducao.md): atalhos do VS Code, Word Wrap, `id` e `class`, especificidade.
2. [HTML: principais tags e boas práticas](html-tags.md): tags da página, texto, links, mídia, listas, tabelas, formulários, vídeo, áudio, `details`, HTML semântico e `type` de botões.
3. [CSS: seletores, propriedades, cores, posicionamento, Flexbox e unidades](css.md): seletores, box model, fontes, `position`, `z-index`, Flexbox completo e unidades.
